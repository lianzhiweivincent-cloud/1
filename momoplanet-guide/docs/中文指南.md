# MomoPlanet 毛毛星球：从照片到电脑桌宠

准备**同一只猫或狗的3张以上生活照**，由 MomoPlanet 制作外观定制桌宠，再由你在 **Mac 或 Windows** 电脑上安装使用。

这里是产品使用指南，不包含桌面客户端源码。

## 1. 选同一只宠物的照片

从已有生活照里选清晰、能展示宠物特征的照片。面部和身体视角、花纹或尾巴细节会有帮助；不要求固定姿势、固定角度或专业拍摄。

整组照片应属于同一只猫或狗，不要混入其他宠物。这些是挑图建议，不是对某组照片结果完全一致的承诺。

[看21.5秒照片指南](https://www.youtube.com/shorts/zaQ7if-S70g)

## 2. 在官网提交并看自己的进度

进入[MomoPlanet官网首页](https://momoplanet-ai.com/?utm_source=github&utm_medium=organic&utm_campaign=desktop_pet_guide_20261004)，登录后按当前流程提交照片。私人宠物照片请在网站提交，不要放到公开评论里。

记住提交时使用的账号。之后回到自己的网站工作区看制作进度，并按自己订单显示的下一步操作。演示视频不能说明你的桌宠是否已就绪，也不要靠等待了多久来猜。

## 3. 就绪后安装并同步

桌宠就绪后，从官网首页进入下载区，Mac 选择 macOS 下载，Windows 选择 Microsoft Store，再按当前安装说明操作。

客户端登录时使用**拥有该宠物的同一账号**，就绪桌宠会自动同步到客户端。**新设备首次同步需要联网。**

如果找不到桌宠，先核对账号和网站工作区的就绪状态；仍需帮助时，使用官网客服入口，说明卡在看进度、安装、登录还是同步。

[看20秒提交后步骤教程](https://www.youtube.com/shorts/1SyG7OQ8_O0)
