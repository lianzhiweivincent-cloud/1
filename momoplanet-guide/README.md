# MomoPlanet desktop pet guide

Start with **3+ everyday photos of the same cat or dog**. MomoPlanet creates a custom desktop companion; you install the app on your **Mac or Windows** computer and sign in with the account that owns your pet.

These are product usage guides. The desktop client's source code is not included.

## Start here

1. [Choose your pet's photos](docs/photos.md): clear views of one pet's features, with no fixed poses required.
2. Submit through the [MomoPlanet homepage](https://momoplanet-ai.com/?utm_source=github&utm_medium=organic&utm_campaign=desktop_pet_guide_20261004), then check progress in your own website workspace.
3. [Install and sync when ready](docs/next-steps.md): choose Mac or Windows, use the same owning account, and connect to the internet for the first sync.
